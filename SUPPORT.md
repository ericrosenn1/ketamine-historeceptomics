# Support

Use [GitHub Issues](https://github.com/ericrosenn1/ketamine-historeceptomics/issues)
for support and bug reports. Search existing issues first and use the closest
issue form.

Include the following information:

- **Installation problem:** operating system, Python and PowerShell versions,
  exact command, complete non-secret error text, and installation lane.
- **Reproducibility failure:** release/tag, mode, input manifest and hashes,
  failing check identifier, output path, and whether the checkout is clean.
- **Scientific-output mismatch:** affected table/field, expected and observed
  value, tolerance, source/input hashes, missingness state, and relevant
  configuration. Do not post restricted inputs.
- **Documentation problem:** page, heading or link, expected behavior, and the
  release viewed.

Security concerns belong in private vulnerability reporting, not Issues; see
[`SECURITY.md`](SECURITY.md). This project does not provide clinical advice or
interpret results for patient care.
