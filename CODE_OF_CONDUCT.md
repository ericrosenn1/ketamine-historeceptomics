# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, level of experience,
education, socioeconomic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

## Expected behavior

Be respectful, constructive, evidence-oriented, and mindful that scientific
disagreement is not personal conflict. Accept responsibility, correct mistakes,
protect confidential or restricted information, and focus criticism on the
work. Harassment, threats, discriminatory language, sexualized attention,
doxxing, and publication of another person's private information are not
acceptable.

## Scope and enforcement

This policy applies in repository spaces and when representing the project.
Report ordinary conduct concerns through a focused GitHub Issue without posting
private information. If a report must remain confidential or concerns a
security issue, use GitHub private vulnerability reporting. The maintainer may
remove content, reject contributions, or temporarily or permanently restrict
participation in response to inappropriate conduct.

This policy is adapted from the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
