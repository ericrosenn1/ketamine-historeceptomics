# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |
| Earlier private development releases | No public support |

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/ericrosenn1/ketamine-historeceptomics/security/advisories/new)
for this repository. Include the affected version, platform, reproduction steps,
impact, and any suggested mitigation. Do not include real credentials or private
data in a proof of concept.

The maintainer will acknowledge a complete report through GitHub, assess impact,
coordinate a fix when warranted, and publish an advisory after a safe release.
Scientific disagreements and reproducibility mismatches are not security issues;
report those through GitHub Issues as described in [`SUPPORT.md`](SUPPORT.md).
